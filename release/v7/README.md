# Dragon Café Game — V7

نسخه V7 منوی دیجیتال کافه گیم دراگون.

## اصلاحات
- رفع خروج «قیمت به تومان» از محدوده در هدر «پیشنهاد ویژه» در موبایل.
- منوی مدیریت دیگر روی فیلدهای «افزودن آیتم» overlay نمی‌شود و نوار پایین مدیریت هنگام باز بودن modal مخفی است.
- «فایلی انتخاب نشده است» در مدیریت منو کاملاً داخل کادر و وسط‌چین می‌ماند.
- موارد بدون تصویر یا تصویر خراب با لوگوی Dragon به عنوان fallback پوشش داده می‌شوند.
- قیمت نهایی با cyan الکتریکی، شیشه آبی/بنفش و قیمت قبلی با coral ملایم تنظیم شده است.
- عنوان سایت «کافه گیم دراگون» در صفحات اصلی حفظ و همگام می‌شود.
- لایه جستجو از نظر z-index و فاصله اصلاح شده است.
- انتخاب تم و رنگ متن نسخه قبلی حفظ شده و کل سایت را تحت تأثیر قرار می‌دهد.

## ساختار انتشار
`index.html` قطعات V6 موجود در `release/v6/` را سرهم می‌کند و patchهای V7 را از `release/v7/` روی آن اعمال می‌کند تا بدون تکرار فایل ۱۹۰KB، نسخه جدید روی GitHub Pages قابل اجرا باشد.
