# V34 — گزارش تغییرات

## هدف
V34 نسخه فعال و پایدارسازی‌شده برای ادامه کار روی رابط منوی کافه گیم دراگون است.

## اصلاحات رابط کاربری
- اصلاح مرکزچینی قیمت و واحد پول در پیش‌نمایش محصول.
- حذف دکمه بستن تکراری و نگه‌داشتن یک دکمه در گوشه چپ بالای تصویر.
- مرکزچینی عدد داخل کنترل کم/زیاد کردن تعداد.
- جلوگیری از شکستن عدد تعداد به سطر بعد.
- حفظ کنترل تعداد به‌صورت سه‌ستونه ثابت.
- مرکزچینی خلاصه تعداد سفارش دریافتی.

## ویرایش سفارش مدیر
مدیر از صفحه سفارشات دریافتی می‌تواند:
- تعداد هر محصول را کم کند.
- تعداد هر محصول را زیاد کند.
- در صورت صفر شدن همه اقلام، سفارش را لغو کند.
- کل سفارش را لغو کند.
- سفارش را پس از ویرایش ذخیره و دوباره در لیست سفارشات مشاهده کند.

هر ویرایش در history سفارش ثبت می‌شود. اگر integration فعال باشد، تلاش برای ارسال PATCH به API مرکزی نیز انجام می‌شود.
