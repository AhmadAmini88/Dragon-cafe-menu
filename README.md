# Dragon Game Café

منوی دیجیتال QR و زیرساخت سفارش‌گیری برای کافه گیم دراگون.

## اجزای پروژه
- `game-cafe-menu-3.html`: نسخه پایدار منوی موبایل با دسته‌بندی عمودی سمت راست و ظاهر آبی شیشه‌ای.
- `dragon-cafe-server/`: سرور مرکزی سفارش‌ها، وضعیت سفارش و Bridge قابل تنظیم زعفران.
- `manifest.webmanifest` و `sw.js`: PWA و کش پوسته برای تجربه آفلاین پایه.
- `docs/dragon-enhancements-2026.md`: مشخصات UX، امنیت و معماری ۲۰۲۶.
- `prototypes/`: نمونه‌های حرکت/Timeline و تست‌های رابط.

## معماری عملیاتی
QR میز → منوی موبایل → سبد → API مرکزی → پنل حسابدار/آشپزخانه → وضعیت زنده → Bridge زعفران.

## نکات مهم
سرور منبع حقیقت سفارش است؛ LocalStorage فقط fallback/کش محلی است. برای استقرار عمومی `ADMIN_API_KEY` تنظیم شود. اطلاعات حساس Bridge زعفران نباید در مرورگر نگهداری شود.

برای اتصال قطعی زعفران، روش یا API معتبر نسخه نصب‌شده باید در Bridge تنظیم شود؛ endpoint ساختگی hard-code نمی‌شود.
