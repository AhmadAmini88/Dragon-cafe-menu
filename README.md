# Dragon Game Café

منوی دیجیتال QR و زیرساخت سفارش‌گیری برای کافه گیم دراگون.

## نسخه فعال
- `index.html`: ورودی اصلی GitHub Pages و لودر نسخه V7.
- `release/v7/patch.css`: اصلاحات responsive، پنل مدیریت و پالت رنگ.
- `release/v7/patch.js`: fallback لوگوی Dragon و همگام‌سازی عنوان سایت.
- `release/v6/`: هسته کامل منوی نسخه قبلی که V7 روی آن patch می‌شود.
- `dragon-cafe-server/`: سرور مرکزی سفارش‌ها، وضعیت سفارش و Bridge قابل تنظیم زعفران.
- `manifest.webmanifest` و `sw.js`: PWA و کش پوسته برای تجربه آفلاین پایه.

## تغییرات V7
- هدر «پیشنهاد ویژه» در موبایل بدون overflow.
- ناوبری پنل مدیریت دیگر روی فرم افزودن آیتم قرار نمی‌گیرد.
- نوار پایین مدیریت هنگام باز بودن modal مخفی است.
- کادر نام فایل در مدیریت منو وسط‌چین و responsive است.
- قیمت‌های عادی و تخفیفی با glass premium و پالت cyan/violet/coral طراحی شده‌اند.
- موارد بدون عکس fallback لوگوی Dragon دارند.
- عنوان سایت «کافه گیم دراگون» است.
- تنظیمات تم و رنگ متن در پنل مدیریت حفظ شده است.

## معماری
QR میز → منوی موبایل → سبد → API مرکزی → پنل حسابدار/آشپزخانه → وضعیت زنده → Bridge زعفران.

## نکات
سرور منبع حقیقت سفارش است؛ LocalStorage فقط fallback محلی است. برای استقرار عمومی `ADMIN_API_KEY` تنظیم شود. اطلاعات حساس زعفران در مرورگر نگهداری نشود.
