# استاندارد انیمیشن و Timeline — Dragon Game Café

## هدف
حرکت‌ها باید حس یک محصول پریمیوم گیمینگ بدهند اما مزاحم سفارش‌دادن نشوند.

## اکشن‌های اصلی

1. **Card entrance**: کارت محصول با fade + translateY کوتاه وارد شود؛ ترتیب کارت‌ها stagger بسیار کم داشته باشد.
2. **Add to cart**: دکمه هنگام لمس یک scale کوچک بگیرد، سپس badge سبد خرید به‌روزرسانی شود.
3. **Glass sweep**: روی hover دسکتاپ یک برق بسیار ظریف روی کارت حرکت کند.
4. **Category active**: آیکون دسته active کمی بالا برود و glow آبی ملایم بگیرد.
5. **Modal**: جزئیات محصول با ورود کوتاه و خروج سریع نمایش داده شود.
6. **New order**: سفارش جدید در پنل آشپزخانه با glow/pulse محدود مشخص شود.
7. **Status transition**: تغییر مرحله سفارش باید با به‌روزرسانی نقطه/خط Timeline دیده شود.

## Timeline مشتری

`سفارش ثبت شد → تأیید شد → در حال آماده‌سازی → آماده تحویل → تحویل شد`

هر مرحله باید تاریخ/ساعت واقعی از history سفارش داشته باشد. مرحله جاری pulse بسیار ملایم دارد؛ مراحل بعدی کم‌رنگ می‌مانند.

## پاسخ‌گویی

برای `prefers-reduced-motion: reduce` تمام انیمیشن‌های تزئینی باید غیرفعال یا حداقلی شوند.

## منطق سفارش

تغییر وضعیت فقط باید از مسیر state machine انجام شود و هر تغییر در `history` ثبت شود. این تاریخچه برای پیگیری مشتری، حسابدار و گزارش‌های بعدی استفاده می‌شود.
