# Dragon Game Café

منوی دیجیتال QR و زیرساخت سفارش‌گیری برای کافه گیم دراگون.

## نسخه فعال
- **V34** نسخه فعال رابط کاربری و سفارشات است.
- `index.html` ورودی اصلی GitHub Pages است و patchهای فعال را بارگذاری می‌کند.
- `release/v6/` هسته اصلی منو.
- `release/v7/` اصلاحات پایه responsive، مدیریت و fallback.
- `release/v32/` اصلاحات modal، تعداد و سفارش.
- `release/v33/` بازطراحی تمیز قیمت/تعداد، پیش‌نمایش و ویرایش سفارش.
- `release/v34/` آخرین لایه فعال برای alignment، پیش‌نمایش و ویرایش سفارش مدیر.
- `dragon-cafe-server/` سرور مرکزی سفارش‌ها و Bridge قابل تنظیم زعفران.
- `manifest.webmanifest` و `sw.js` برای PWA و کش پوسته.

## مستندات بازیابی پروژه
برای ادامه پروژه در گفت‌وگوی جدید، ابتدا این فایل‌ها را بخوانید:
- `docs/PROJECT_STATE.md` — وضعیت کامل، معماری، قواعد UI، منطق سفارش و نقاط ادامه.
- `docs/CHANGELOG_V34.md` — تغییرات و commitهای V34.

این دو فایل مرجع سریع ادامه کار هستند و باید همراه با کد V34 مطالعه شوند.

## قابلیت‌های فعال V34
- پیش‌نمایش محصول با یک دکمه بستن در گوشه چپ بالای تصویر.
- قیمت و واحد پول در پیش‌نمایش محصول به‌صورت گروه واحد و مرکزچین.
- کنترل تعداد سه‌قسمتی با عدد کاملاً وسط‌چین.
- قالب تعداد سفارش: تعداد - X عدد.
- ویرایش تعداد اقلام توسط مدیر.
- لغو سفارش توسط مدیر.
- ثبت تاریخچه ویرایش سفارش.
- ارسال PATCH به API مرکزی در صورت فعال بودن integration.
- وضعیت سفارش با ساختار قابل توسعه و نمایش responsive.

## معماری
QR میز → منوی موبایل → سبد → API مرکزی → پنل حسابدار/آشپزخانه → وضعیت زنده → Bridge زعفران.

## قواعد مهم
- Mobile-first.
- Glassmorphism با پالت آبی/سرمه‌ای و accentهای cyan/violet/coral.
- منوی دسته‌ها در سمت راست.
- قیمت و کنترل تعداد نباید باعث جابه‌جایی سطر شوند.
- محصول بدون تخفیف نباید کادر قیمت قرمز خالی داشته باشد.
- قیمت‌های تخفیف‌دار باید کامل و بدون clipping نمایش داده شوند.
- مبلغ نوار پایین نباید از کادر خارج شود.
- متن وضعیت سفارش باید کامل و وسط‌چین باشد.

## سفارش و امنیت
سرور منبع حقیقت سفارش است؛ LocalStorage فقط fallback محلی است. برای استقرار عمومی ADMIN_API_KEY تنظیم شود. اطلاعات حساس زعفران در مرورگر نگهداری نشود.
